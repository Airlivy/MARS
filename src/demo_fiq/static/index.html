🖼️ 组合图像检索 · 交互 Demo

点选参考图 + 输入修改指令 → CLIP 融合检索（排除参考图本身）
用法：左侧图库点一张图作参考图，输入中文修改指令（如「把蓝色改成红色」），点「检索」。 引擎为轻量 CLIP（无 LLM、无重排序），为课程框架的 Stage-1 检索做可交互演示。 图库是 真实 FashionIQ 服装图（dress/shirt/toptee，上万张），网格只展示部分、可「加载更多」， 检索在全库进行；点击结果图可继续把它当新参考图。下方「推荐演示案例」已离线筛出，一键复现。
